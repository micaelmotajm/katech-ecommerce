PROJETO: KaTech! - Loja Virtual de Hardware e Periféricos
DISCIPLINA: Desenvolvimento Web (HTML5, CSS3 e JavaScript)

INTEGRANTES DA DUPLA:
1. Paulo Vitor Souza Dias
2. José Micael Mota Chagas

DESCRIÇÃO DO PROJETO:
Loja virtual fictícia inspirada na identidade visual do KaBuM!, desenvolvida com HTML5 semântico, CSS3 (Grid, Flexbox e Media Queries) e JavaScript puro com persistência de dados via LocalStorage.

ESTRUTURA DE ARQUIVOS:
- index.html: Página inicial com banner, barra de busca, filtro por categorias e catálogo com 6 produtos.
- carrinho.html: Página de carrinho com controle de quantidade, remoção de itens e cálculo automático do valor total.
- css/style.css: Folha de estilos responsiva.
- js/script.js: Lógica de carrinho, LocalStorage e filtros de pesquisa.
- images/: Imagens dos 6 produtos exibidos na loja.

COMO EXECUTAR:
Basta abrir o arquivo "index.html" diretamente em qualquer navegador web moderno (Google Chrome, Edge, Firefox).
